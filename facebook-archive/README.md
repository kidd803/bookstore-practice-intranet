# 林宜毅 Facebook 貼文整理流程

這個資料夾沿用圓安道長內網的做法，專門整理林宜毅 Facebook 官方匯出的貼文資料。

## 匯出設定

- 個人檔案：林宜毅 / Facebook
- 臉書網址：<https://www.facebook.com/www.2books.com.tw/>
- 資料範圍：不限時間
- 自訂資訊：貼文
- 格式：JSON
- 影像畫質：中等品質

Meta 會先準備檔案，完成後會通知 `lknatw.bt@gmail.com` 可以下載。下載後，把 ZIP 放在 `~/Downloads`，再執行：

```bash
node tools/organize-facebook-export.mjs
```

也可以指定 ZIP：

```bash
node tools/organize-facebook-export.mjs /path/to/facebook-export.zip
```

## 下載前檢查

Facebook 匯出檔很大，下載前先檢查本機是否已經有同日期的檔案或已解壓資料。

- 先看 `facebook-archive/download-log.json`
- 再看 `~/Downloads` 是否已有同日期 ZIP 或 `your_facebook_activity`
- 若同一天已下載過，直接用本機檔案整理，不要重新下載
- 只有 Facebook 顯示新日期、且本機沒有對應檔案時，才進 Chrome 下載

## 輸出位置

- `outputs/facebook_posts/posts.json`：完整貼文索引
- `outputs/facebook_posts/markdown/`：一篇貼文一個 Markdown 檔
- `outputs/facebook_posts/duplicate-report.md`：重複文章合併與疑似重複報告
- `site/data/posts.js`：內網會讀取的資料
